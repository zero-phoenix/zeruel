# Política de privacidad — Zeruel

Zeruel es una herramienta personal de un único usuario (su propietario). No ofrece servicio a terceros.

- **Datos solicitados:** solo el correo de la cuenta de Google (`userinfo.email`), para verificar que quien la usa es el propietario.
- **Uso:** el correo no se guarda, vende ni comparte; solo se compara con el del propietario.
- **Almacenamiento:** solo estados y métricas sintéticos, sin datos personales.
- **Revocación:** https://myaccount.google.com/permissions
- **Contacto:** issues en https://github.com/zero-phoenix/zeruel
