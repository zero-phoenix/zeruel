# Política de privacidad — Zeruel

## Archivo privado autorizado — 30/09/2026

El repositorio GitHub es **PRIVADO**, por instrucción expresa del propietario. `knowledge/` conserva íntegros expedientes, resoluciones, cédulas y controles Excel de las dos carpetas indicadas, con índices y contexto para continuar tras formatear. Contiene datos personales reales. Las reglas siguientes describen solamente el servicio sintético, no el archivo GitHub. No volver público el repositorio ni servir el archivo desde la web. Se excluye del contexto Docker. No se incorporaron credenciales ni se borraron fuentes.

Zeruel es una herramienta personal de un único usuario (su propietario). No ofrece servicio a terceros.

- **Datos solicitados:** solo el correo de la cuenta de Google (`userinfo.email`), para verificar que quien la usa es el propietario.
- **Uso:** el correo no se guarda, vende ni comparte; solo se compara con el del propietario.
- **Almacenamiento:** solo estados y métricas sintéticos, sin datos personales.
- **Revocación:** https://myaccount.google.com/permissions
- **Contacto:** issues en https://github.com/zero-phoenix/zeruel
